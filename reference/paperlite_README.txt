PaperLite — Image to PDF (Standalone Module)

RUN:
1. Extract this folder.
2. Double-click START.bat.
3. Open http://127.0.0.1:8767

Local processing only. No paid API or remote conversion service.
The first launch installs Flask and Pillow. Processing runs on your PC.

Features:
- Merge images into one multi-page PDF.
- Create separate PDFs, delivered together in a ZIP.
- Reorder images before conversion.
- A4, A5, Letter and Original page sizes.
- Auto, Portrait and Landscape orientation.
- Show full photo or Fill the page.
- Normal: automatic quality/file-size balance.
- Custom Size: dropdown options are calculated from the total uploaded image size, with a Custom entry for manual KB/MB.
- Custom values above the original total are automatically capped to the original total.
- Actual output size and warning if requested limit cannot be met.

Important:
- Target size is a maximum goal, not a guarantee. Some image sets cannot fit without reducing readability.
- In separate-PDF mode, the selected target applies to each individual PDF.
- Transparent image backgrounds are rendered white in PDF.
- Maximum upload: 200 MB total; maximum 100 images.
- Keep the terminal open while using the app.

PDF size selector update: Uploaded image bytes and estimated PDF bytes are shown separately. Estimate is generated locally using the selected page settings; custom limits are based on estimated PDF size, not source image size. The selected size is a maximum target, not a promise of exact output size.
